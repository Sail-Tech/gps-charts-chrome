GPS input

Uses this device's own location. On a phone or tablet that is its GPS; a laptop usually only knows its Wi-Fi location. Speed and course come from the device and are less steady than a boat GPS. The screen is kept on while connected.

TCP/UDP: run bridge/gps_bridge.py and connect to the local WebSocket. For N2K, set the gateway to output NMEA 0183, JSON or Signal K.

Chrome only lists ports you have authorised. Add port… opens Chrome's picker with every port on the system. Scan ports listens on each authorised port at the common baud rates and selects the one that sends valid NMEA.

Provider page

Both providers show the boat without reloading the page. i-Boating draws its own boat marker with a heading line and keeps your zoom; with auto-centre off the marker still moves but the chart stays put. C-MAP shows the boat as a Pinned location, but resets its zoom on each update and ignores the URL zoom; a longer interval leaves time to zoom in between.

Dashboard chart

Open bathymetry from Open Waters · EMODnet/GEBCO. In European waters the source is usually EMODnet (~115 m); it is not equivalent to C-MAP HRB or sonar contours.

Offline cache

—

Every tile you view (chart, seamarks, bathymetry and labels) is stored. When the internet drops, the dashboard serves stored tiles automatically. The Esri base chart is cached as you view it, but not bulk-saved, as Esri does not allow tile export. OpenStreetMap does not allow offline storage, so its tiles only use the browser's own cache: recently viewed areas usually stay visible offline, but not reliably. The C-MAP and i-Boating sites themselves need internet access.
